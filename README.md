# Overshare

A social quiz and confession app for friends. Send a question, answer privately, and compare results through a mutual reveal.

## Features

* Card-based feed of quizzes from friends
* Quiz creation flow with multiple question types (Either/Or, Choose One, Yes/No, Predict)
* Private answers with a mutual reveal
* Anonymous public posts, visible privately on your own profile
* Favorite quizzes with a tap
* Color palettes with automatic text contrast for readability

## Status

Prototype in active development.
